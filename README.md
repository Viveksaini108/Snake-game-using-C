# Snake Game in C

The classic Snake game, written in **C** (with a C++ version included).

## How it works

- The snake moves around the board and grows longer each time it eats the food
- The game speeds up the challenge as your score climbs — hit a wall or your own tail and the game is over
- Score is tracked as you play

## Files

- `game.c` — the C version
- `game.cpp` — the C++ version

## How to run

Compile and run with any standard compiler, for example:

```bash
gcc game.c -o snake
./snake
```

or on Windows:

```bash
gcc game.c -o snake.exe
snake.exe
```
